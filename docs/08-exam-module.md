# 模拟考试模块说明

版本：0.1
日期：2026-11-23

## 1. 闭环

```text
知识图谱
  -> 可编辑考试蓝图
  -> DeepSeek 出卷
  -> 本地结构校验
  -> 试卷预览
  -> 计时作答
  -> 客观题自动判分
  -> 主观题评分点自评
  -> 薄弱知识点
  -> 本地考试记录与错题
```

## 2. 蓝图

默认 C++/MFC 蓝图：

| 题型 | 题量 | 每题分值 | 小计 |
| --- | ---: | ---: | ---: |
| 单项选择题 | 10 | 2 | 20 |
| 代码阅读题 | 4 | 10 | 40 |
| 程序设计题 | 2 | 20 | 40 |
| 合计 | 16 |  | 100 |

用户可以修改题量、单题分值、总分、时长、难度和额外要求。生成前要求：

- 每个分区 `题量 × 单题分值 = 分区总分`
- 所有分区总分等于试卷总分
- 难度比例合计为 100%

## 3. 后端接口

`POST /api/exam/generate`

请求包含：

- 课程名称、语言和框架
- 蓝图
- 当前知识图谱
- 额外要求

响应包含：

- 试卷标题
- 分值与题目
- 答案、解析和评分点
- 生成模型和警告

生成结果保存在 `local-samples/generated/`，该目录被 Git 忽略。

## 4. 本地结构校验

后端在返回试卷前校验：

- 每个题型分区的题量
- 每题分值与蓝图一致
- 分区总分与总分一致
- 题目知识点存在于当前图谱
- 选择题包含选项和答案
- 非选择题包含评分点
- 代码题不错误使用 Python

结构不合格时返回明确错误，不把半成品展示为成功试卷。

## 5. 作答与判分

客观题：

- 单选、多选、判断题自动判分
- 当前首版主要使用单选

主观题：

- 代码阅读、程序设计、计算和证明题按评分点勾选
- 得分按已勾评分点数量比例计算
- 用户必须自行核对实际作答，不宣称 AI 自动批改

## 6. 本地数据

- `last-paper`：最近一次生成的试卷
- `exam-history`：最近 10 次考试结果
- `wrong-book`：错题 ID

内容只保存在当前浏览器，不上传到项目作者服务器。

## 7. 历年真题

考试蓝图支持上传图片格式的历年真题：

1. `deepseek-flash` 识别题区、题量、分值和知识点。
2. 命题画像展示考试时长未知、分值矛盾等不确定性。
3. 用户确认后应用到蓝图。
4. 同一大题内不同小问分值使用评分组保存，不拆分大题。
5. 应用后仍可手工修改每个小问的题量和分值。

## 8. 当前边界

- 不执行 C++ 代码
- 不自动批改主观题
- 错题本仅有存储和数量，完整错题管理页尚未接入
- 收藏题目尚未接入
- 大学物理内置样例尚未接入
- 历史试卷快照和进行中考试的跨刷新恢复尚未完成
