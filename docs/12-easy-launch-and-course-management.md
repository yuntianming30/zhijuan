# 双击启动、动态课程与新手配置

版本：0.1
日期：2026-11-24

## 本次解决的问题

### 导航入口不可用

原侧栏只启用“复习导图”和“模拟考试”，其余入口被硬编码为禁用。现在以下页面均可直接进入：

- 课程资料
- 复习导图
- 模拟考试
- 历史记录
- 错题本
- 收藏

历史记录会合并课程创建、资料处理、导图生成和模拟考试记录。考试试卷会额外归档，供错题本和收藏页面显示题目、答案与解析。

### 只能使用预设课程

课程列表改为本地持久化数据结构。用户可以：

- 从侧栏或顶部工具栏新建课程
- 填写课程名称、说明、编程语言、框架或工具
- 选择课程颜色
- 在自建课程中独立上传资料、生成导图和考试
- 刷新页面后继续使用原课程

内置课程仍保留，已有导图和考试数据键保持兼容。

### 新用户不知道如何配置 DeepSeek

设置页新增“第一次使用 DeepSeek？”引导，说明：

- 注册和登录官方开放平台
- 按实际用量充值，知卷不代收费用
- 创建并妥善保存 API Key
- 粘贴 Key、测试连接和保存配置
- 测试后根据接口返回的模型列表修正模型名称

价格、赠送额度和支付方式可能变化，因此页面只提供官方入口，不硬编码金额。

### 必须使用终端启动

新增 Windows 双击启动：

- `start-zhijuan.vbs`：隐藏命令行窗口，自动准备并打开网页
- `start-zhijuan.cmd`：保留可见日志，便于排查首次安装问题
- `scripts/start-zhijuan.ps1`：实际启动逻辑

启动器自动执行依赖哈希检查、虚拟环境创建、依赖安装、前端构建、端口选择和本地服务启动。服务启动后日志和 PID 位于 `local-samples/launcher/`，该目录不会提交到 Git。
